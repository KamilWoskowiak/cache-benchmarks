Detailed Description

template<storable V>
class alc::cache_handle< V >

References a lifetime-constrained piece of cached data.

The handle does not own the referenced data and must be outlived by the owner. If so, then references to the data are invalidated only once the handle is destructed.

A handle cannot be null. A handle cannot be default constructed. A handle cannot be copied.
