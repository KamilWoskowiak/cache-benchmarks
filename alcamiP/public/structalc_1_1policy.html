Detailed Description

template<summary S, prioritizer< S > Prio, combiner< prioritizer_priority_t< S, Prio > > Comb>
struct alc::policy< S, Prio, Comb >

Represents a caching policy.

Determines the best item to evict from a cache to make room for a new item. The priority and summary types are assumed to be cheap-to-copy, while the prioritizer and combiner types are assumed to be cheap to call. All function objects must be thread- and exception-safe.

Items with a lower priority should be evicted first. A cache implementation tries to keep the highest priority items in the cache.
