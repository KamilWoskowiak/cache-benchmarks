auto alc::cache_manager< K, V, Map, Pol, Summ >::lookup ( key_type  key) const -> std::optional<handle_type>
inline

Returns a lifetime-constrained reference to the data that the mapping associates with the given key.

The data referenced by the returned handle lives only as long as the handle, and the handle lives only as long as this object.

Returns no value if all slots in the cache are being accessed.
